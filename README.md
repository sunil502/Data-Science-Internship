# Week 1 — Excel & Data Analyst Assignment

## Assignment
This project follows the uploaded Week 1 brief:
- Excel basics: SUM, AVERAGE, COUNT
- Data cleaning techniques
- Pivot-table/data summarization
- Descriptive statistics: mean, median, mode, variance
- Sales dashboard covering:
  - Total Revenue
  - Sales by Category
  - Yearly Sales Trends
  - Department-wise Revenue

## Important note
