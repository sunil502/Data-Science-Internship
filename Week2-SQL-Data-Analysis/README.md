# Week 2 — SQL for Data Analysis

## Assignment
This project covers the Week 2 requirements:
- SELECT, WHERE, GROUP BY, ORDER BY
- SUM, AVG, COUNT
- JOINs
- Subqueries
- CASE statements
- Top customers
- Average order value

## Database
Database: `week2_sales`

Tables:
- `customers`
- `orders`

The project contains 10 customers and 50 sample orders.

## Folder
```text
Week2-SQL-Data-Analysis/
├── README.md
├── schema.sql
├── sample_data.sql
├── queries.sql
└── GITHUB_GUIDE.md
```

## Run in MySQL Workbench
1. Open MySQL Workbench.
2. Open `schema.sql` and run it.
3. Open `sample_data.sql` and run it.
4. Open `queries.sql` and run individual queries.

## Main assignment results
The final queries identify:
- Top 5 customers by total spending
- Average order value

The database is self-contained because the assignment text supplied here does not include an actual database file/schema.
